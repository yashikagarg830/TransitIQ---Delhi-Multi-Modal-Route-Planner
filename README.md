# TransitIQ 🚇

### Delhi Multi-Modal Route Planner

TransitIQ is a multi-modal transportation route planner designed to help commuters in Delhi find and compare journeys using Metro, buses, auto-rickshaws, and walking.

The project aims to optimize journeys based on travel time, estimated fare, distance, walking requirements, and transfers using graph-based algorithms implemented in C++.

## Problem Statement

Commuters in large cities like Delhi often need to combine multiple transportation modes to reach their destinations. Finding the fastest, cheapest, or most convenient combination of transport can be difficult.

## Proposed Solution

TransitIQ will calculate and compare different journey options, allowing users to choose routes based on their preferences.

## Transportation Modes

- 🚇 Metro
- 🚌 Bus
- 🛺 Auto-rickshaw
- 🚶 Walking

## Planned Features

- Source and destination search
- Multi-modal route calculation
- Fastest route recommendation
